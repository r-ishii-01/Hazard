# 標高タイルのローカルミラー（`public/tiles/`）

このディレクトリには、国土地理院の標高タイルの複製（ローカルミラー）を置きます。
サイトは地形を読み込むとき、まずここ（`<サイトのURL>/tiles/manifest.json` とタイル画像）を探し、
無いタイルだけを国土地理院のサーバー（`https://cyberjapandata.gsi.go.jp/xyz/...`）から直接取得します。
どちらからも取得できない場合は、概略の「簡易地形モデル」で代用し、画面にその旨を表示します。

ミラーを置いておくと、

- 国土地理院のサーバーに接続できない環境（社内ネットワーク、オフライン展示など）でも実際の地形で計算できる
- 読み込みが速く、国土地理院のサーバーへの負荷も減る

という利点があります（置かなくてもサイトは動作します）。

## 作り方

リポジトリのルートで次を実行します（Node.js 20 以上）。

```sh
node scripts/prefetch-dem.mjs            # ダウンロード（保存済みのタイルはスキップ）
node scripts/prefetch-dem.mjs --dry-run  # ダウンロードせずに URL の一覧だけ表示
node scripts/prefetch-dem.mjs --force    # すべて取り直す
```

- 対象は計算範囲（`src/core/geo.ts` の `DOMAIN_BOUNDS`：辻堂〜鵠沼〜片瀬・江の島）を覆うタイルです。
  - DEM5A / DEM5B / DEM5C（`dem5a_png` / `dem5b_png` / `dem5c_png`、ズーム 15）
  - DEM10B（`dem_png`、ズーム 14）
- 全部で 156 枚を確認し、データのある分（数十枚・合計 数 MB 程度）を保存します。
  海だけのタイルなどは国土地理院側にも存在せず（HTTP 404）、`manifest.json` に「データなし」として記録します。
- 同時接続は 4 以下、リクエストごとに待ち時間を入れています。
- HTTPS プロキシの内側で実行する場合は、Node.js がプロキシを使うように環境変数を付けます
  （Node.js 22.21 / 24.5 以降）:

  ```sh
  NODE_USE_ENV_PROXY=1 node scripts/prefetch-dem.mjs
  ```

作られるファイル:

```
public/tiles/
  manifest.json                 取得結果の一覧（1 = 保存済み、0 = 国土地理院にもデータなし）
  dem5a_png/15/<x>/<y>.png      DEM5A（航空レーザ測量による 5m メッシュ）
  dem_png/14/<x>/<y>.png        DEM10B（10m メッシュ）
  ...
```

`vite build` を実行すると `public/` の内容はそのまま `dist/` にコピーされるので、ビルドしたサイトにもミラーが含まれます。
計算範囲（`DOMAIN_BOUNDS`）を変えたときは、スクリプトを再実行してください。

## 出典の表示（必須）

標高タイルは国土地理院のコンテンツです。利用・複製・加工して公開する際は、
[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html) に従い出典を明示してください。
このサイトでは、地形の情報パネルに次のように表示しています（加工して利用していることも明記）。

> 地理院タイル（標高タイル（基盤地図情報数値標高モデル））を加工して作成（国土地理院 DEM5A）
> 出典: 国土地理院「地理院タイル（標高タイル）」 https://maps.gsi.go.jp/development/ichiran.html#dem

（「地理院タイル（標高タイル（基盤地図情報数値標高モデル））を加工して作成」は、同規約の「コンテンツを編集・加工等して利用する場合」の記載例の文言です。）

標高タイルの仕様: [標高タイルの詳細仕様](https://maps.gsi.go.jp/development/demtile.html)（国土地理院）

## 注意

- 標高タイルには海の水深が含まれません。このサイトの海底地形は、汀線からの距離に応じた**推定値**です。
- 本サイトのシミュレーションは学習用の簡易計算であり、公式の津波浸水想定ではありません。
  避難の判断には、藤沢市の津波ハザードマップや神奈川県の津波浸水想定を確認してください。
